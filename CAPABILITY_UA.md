# Артур Онисько — AI-процеси, які можна перевірити

Пишу код для автоматизацій та агентних сценаріїв. Мені важливо, щоб людина могла побачити, звідки взявся результат, чому система пішла далі або зупинилася і хто вирішує, що робити після цього.

## Що можна відкрити зараз

[Evidence-gated Agent Workflows](https://github.com/DiadkoShmek/evidence-gated-agent-workflows) — сім локальних прикладів перевірки даних, обмеженого очікування, відмови при конфлікті й передачі результату на людський розгляд. Репозиторій містить код, тестові приклади та команду відтворення:

```bash
python3 run_proof.py
```

Приклади працюють із синтетичними даними. Вони не є клієнтським впровадженням і не доводять безпеку іншої системи.

## Якщо у вас є схожа задача

Можна почати з короткого опису: що є джерелом, куди переходить результат, яка помилка коштує найбільше й що було б корисно перевірити спочатку. Не надсилайте ключі, приватні дані чи доступ до робочої системи у публічному зверненні.

Напишіть через [профіль GitHub](https://github.com/DiadkoShmek) або [LinkedIn](https://github.com/DiadkoShmek). Обсяг роботи й умови варто визначати після розмови про конкретну задачу.
