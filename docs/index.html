A concrete exchange

What you supply. What “done” means.

You supply: one sanitized sample artifact, its expected schema, the source and target interface descriptions, and one costly failure the adapter must refuse. No credentials or production access are required for the pilot.

Acceptance: the agreed valid fixture passes; missing, malformed, stale, substituted, and contradictory fixtures fail closed; the decision trace names the reason; the documented proof command passes; known limits and unresolved blockers are written down.

Handoff: one review round is included. Production deployment, certification, SLA, ongoing support, client-system access, and automatic activation are not included. Repository and licensing terms are agreed before work begins.

Public, runnable evidence

Inspect the method before buying the sprint.

The repository contains dependency-free references for evidence gates, bounded asynchronous polling, operator handoff, and explicit terminal failure states. One command runs this demo's test suite; it is not a safety guarantee for a future client adapter.

python3 run_proof.py

What this proves

  • Missing evidence does not become success.
  • Retries and polling have hard bounds.
  • Duplicate effects and ambiguous outcomes are held.
  • Human approval remains explicit.

What it does not prove

Production deployment, client results, security certification, or access to your systems.
