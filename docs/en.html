Three useful questions

What happens after the AI produces a result?

An answer can look convincing even when a source is missing or out of date. If a message or system change follows automatically, that mistake has a real effect.

01

Where does it go?

Into an email, a spreadsheet, another tool, or a person's review? The next step tells you what is at stake.

02

When should it stop?

In the public examples, missing, stale, or conflicting information stops the handoff.

03

Who decides next?

The test shows why it stopped. A person still reviews any consequential next action.

You can see this in the test examples. If a similar mistake happens in your work, describe one case and we can begin by finding what needs checking.

From example to real question

One failure is enough to begin.

A sanitized description is enough: what enters the system, where the result goes, and which mistake causes the most trouble. The first conversation needs no credentials, private files, or production access.

Then we can define a small check: a valid example passes, broken ones stop with a reason. Any real work needs its own scope and agreement.

The public code uses synthetic data. It is not a client deployment and performs no external action.

Public, runnable evidence

Run the examples and inspect the method.

The repository contains dependency-free references for evidence gates, bounded asynchronous polling, operator handoff, and explicit terminal failure states. One command runs this demo's test suite; it is not a safety guarantee for a future client adapter.

python3 run_proof.py

What this proves

  • Missing evidence does not become success.
  • Retries and polling have hard bounds.
  • Duplicate effects and ambiguous outcomes are held.
  • Human approval remains explicit.

What it does not prove

Production deployment, client results, security certification, or access to your systems.

Where this helps

When an AI answer becomes someone's action.

For example, a program passes a result to another tool, waits for a service, or decides whether its sources are enough for a conclusion.

If we cannot make an honest check, that is also a result: name what is missing instead of calling an unknown outcome a success.
