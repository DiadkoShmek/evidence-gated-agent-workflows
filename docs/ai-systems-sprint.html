Four engineering seams

Choose the transition your team cannot afford to guess about.

1. Memory or retrieval → next-agent context

Bind: subject or tenant, record identities, source revision, query/filter parameters, embedding or retrieval configuration, and the exact returned context.

Refuse: stale facts, wrong-subject memory, cross-collection results, missing source identity, changed selection, or an incomplete context family.

2. Dataset or evaluation → release decision

Bind: dataset items, prompt or agent revision, scorer code/configuration, completed run identity, required scores, thresholds, and the declared consumer decision.

Refuse: partial runs, missing scores, mixed revisions, foreign datapoints, mutable result substitution, or a release conclusion detached from its evaluated bytes.

3. Tool or model result → external effect

Bind: request identity, tool/schema version, arguments, result, attempt history, known effect identity, and explicit action authority.

Refuse: schema-valid but unowned calls, ambiguous retries, unknown outcomes, duplicate effects, conflicting receipts, or a review record presented as execution permission.

Runnable reference: the checked-in agent action admission demo commits a typed synthetic request, exact pre-state and simulator contract before a deterministic local transition. It grants no real tool or effect authority.

4. Workflow or sandbox state → later continuation

Bind: workflow revision, step/attempt identity, input and output artifacts, persisted state or volume generation, terminal status, and the next eligible step.

Refuse: stale checkpoints, foreign runs, last-writer ambiguity, incomplete artifact publication, replay conflict, or continuation after an unproven terminal state.
